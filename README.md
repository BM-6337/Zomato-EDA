# Zomato Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Zomato Bengaluru restaurant dataset to uncover trends in restaurant ratings, customer voting behavior, pricing patterns, restaurant categories, and online ordering preferences.

Using Python-based data analysis and visualization techniques, the project extracts meaningful insights that help understand customer preferences and restaurant performance across different segments.

## Features

- Data cleaning and preprocessing
- Restaurant rating analysis
- Customer voting trend analysis
- Restaurant category distribution
- Online ordering behavior analysis
- Cost distribution analysis
- Correlation and pattern visualization
- Business insight generation through EDA

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset used for this project is not included in this repository due to GitHub file size limitations.

You can download the dataset from Kaggle:

https://www.kaggle.com/datasets/rajeshrampure/zomato-dataset

### Dataset Overview

- Bengaluru restaurant dataset
- 50,000+ rows
- 17 columns
- Includes restaurant ratings, votes, cuisines, pricing, online ordering, table booking, and other restaurant attributes

### Running the Project in Google Colab

1. Download the dataset from the Kaggle link above.
2. Upload the CSV file to your Google Colab environment.
3. Rename the file to `Zomato data .csv` to match the filename used in the notebook, or modify the `pd.read_csv()` statement accordingly.
4. Run the notebook.

> Note: The analysis was performed using the original Kaggle dataset structure. Changes to column names or dataset format may require code modifications.
